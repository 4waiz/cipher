CIPHER contributes a task definition, a traceable set of real AGENTS.md instruction pairs with controlled variants, and
an annotation protocol for blinded labeling. In this preliminary evaluation without human labels, a local open-weight
model given the evidence packet resolved directory scope as reliably as a pipeline that computes it explicitly, and at
lower cost, whereas a scope-blind keyword heuristic flagged one out-of-scope pair (and its order control) as a conflict;
no model arm judged any mined pair a genuine conflict. The open problem is condition-based and implicit applicability,
where the arms disagree, and repeated runs show that single-run differences of a few cases are not reliable evidence.
Collecting independent human labels for those cases, repeating runs, and testing other models and loading profiles are
the next steps.
