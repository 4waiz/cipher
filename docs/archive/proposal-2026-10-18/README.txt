CIPHER research package
Prepared 18 October 2026

This package contains a research proposal, not a completed empirical study. No dataset size, model accuracy, or prototype outcome is claimed as a result.

CIPHER_Paper.pdf contains the authors supplied by the user. CIPHER_Anonymous.pdf is an alternative with no author identities. Confirm TEXTUAL's actual review-anonymity rule before selecting a version. The exact workshop paper categories and length limit were not verified.

The editable Word manuscript and the IEEE conference LaTeX sources contain the same substantive paper. The PDF uses IEEEtran in conference mode. Compile CIPHER_Paper.tex or CIPHER_Anonymous.tex in a LaTeX installation with IEEEtran and the fontenc, url, array, and hyperref packages. Run pdflatex twice. Overleaf normally provides these packages. No shell escape is needed.

The bibliography is embedded in each .tex file. CIPHER_Reading_List.txt provides all research and venue links. CIPHER_Abstract.txt is copyable registration text; confirm any portal word limit. The separate guide provides the annotation protocol, baselines, metrics, work plan, source caveats, and verified submission link.

This package has not been submitted or published. All authors must review and approve the final content. The AI assistance acknowledgment describes the assistance used to prepare this draft and should be updated truthfully after subsequent work.
