# Site data contract

The website under `site/` is a static presentation of files generated by the research pipeline. It never computes
research numbers itself and never calls a model. All numbers shown come from these generated files.

Build: `python site/build.py` (standard library only) copies `site/src/` to `site/dist/`, copies generated data and the
compiled paper into place, and writes the `/paper/` page. Deployed base path: `/cipher/` on GitHub Pages
(https://4waiz.github.io/cipher/). All internal links are relative so that the same build works from `file://`,
a local server, and `/cipher/`.

## Inputs produced by the pipeline (may be missing; the site must show a plain "not yet available" state)

| File (repository-relative) | Producer | Content |
|---|---|---|
| `analysis/exports/status.json` | `analysis/export_site.py` | `{"version": "0.3.0", "date": "2026-10-23", "status_label": "...", "git_commit": "...", "results_available": false}` |
| `analysis/exports/results.json` | same | `{"available": bool, "reason": str, "tables": [Table], "figures": [Figure], "limitations": [str]}` |
| `analysis/exports/replay.json` | same | `{"available": bool, "reason": str, "cases": [ReplayCase]}` |
| `paper/build/cipher-paper.pdf` | `paper/build.py` | Compiled IEEEtran manuscript (named-author version) |
| `paper/build/paper.html` | `paper/build.py` | HTML body fragment of the same manuscript, with `<section id=...>` anchors, figures referenced as `figures/<name>.svg` |
| `paper/build/figures/*.svg` | `analysis/figures.py` | Figures used by both the PDF and HTML |
| `paper/build/meta.json` | `paper/build.py` | `{"title", "authors": [{"name","affiliation","email"}], "abstract", "version", "date", "citation_bibtex", "pdf_sha256"}` |

`Table` = `{"id": str, "title": str, "caption": str, "columns": [str], "rows": [[str|number|null]], "notes": str}`
(render generically; null renders as an en-dash meaning "undefined" with a tooltip "undefined: empty denominator").

`Figure` = `{"id": str, "title": str, "caption": str, "path": "figures/<name>.svg"}`.

`ReplayCase` =
```
{
  "case_id": "E-07-c",            // opaque, never reveals label
  "stratum": "original | context_variant | order_control",
  "parent_case_id": "E-07" | null,
  "changed_property": null | "target_path" | "source_placement" | "evidence_order",
  "repo": "owner/name", "commit": "40-hex", "license": "MIT",
  "task": str, "task_origin": "researcher-authored",
  "target_path": str, "loaded_set": [str],
  "rule_a": {"path": str, "start_line": int, "end_line": int, "heading": str, "text": str},
  "rule_b": {...},
  "reference": {"label": str|null, "status": "adjudicated|agreed|pending", "annotator_1": str|null, "annotator_2": str|null, "adjudication_reason": str|null},
  "predictions": {"B0": {"conflict_flag": bool}|null, "B1": {"label": str, "abstained": bool, "explanation": str, "evidence": [str], "error": str|null}|null, "B2": {...}|null}
}
```

Labels (fixed order): "Unresolved conflict", "Valid override", "Disjoint applicability", "Compatible", "Insufficient evidence".
